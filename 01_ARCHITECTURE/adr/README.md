# Architekturentscheidungen (ADR)

Jede Entscheidung mit erkennbarer Reichweite wird hier festgehalten: Kontext,
geprüfte Optionen, Entscheidung, Konsequenzen — und die Bedingung, unter der
sie falsch wäre.

Eine ADR wird nie gelöscht. Sie wird durch eine neue ersetzt und erhält den
Vermerk `Ersetzt durch ADR-xxxx`.
